# Creative Offer Patterns

## Standard Tier Pattern

Use three tiers when the user wants a sales-ready offer.

| Tier | Purpose | Typical scope |
|---|---|---|
| Starter | Easy yes | 1 core asset, 1 revision, short timeline |
| Core | Recommended package | Main asset set, 2 revisions, cleaner handoff |
| Premium | Best result | Full asset set, strategy, priority timeline, extras |

## Common Offers

### Logo / Brand Starter

- Starter: logo cleanup or simple logo concept
- Core: logo, color palette, typography direction, social avatar
- Premium: logo suite, mini brand guide, social launch graphics

### Flyer / Promo Campaign

- Starter: one flyer
- Core: flyer plus story/post versions
- Premium: full promo pack with captions, event banner, and resize set

### Website Starter

- Starter: one-page landing page
- Core: multi-section starter website with inquiry CTA
- Premium: website plus domain setup, intake form, basic SEO, and maintenance

### Social Media Visual Kit

- Starter: 3 templates
- Core: 10 templates
- Premium: 20 templates plus posting guide and campaign graphics

## Upsells

- Monthly maintenance
- Rush delivery
- Extra revisions
- Social media resize pack
- Website intake form
- Domain setup
- Brand audit snapshot
- Google Business Profile graphics
- Menu, pricing sheet, or service list redesign

## CTA Patterns

- “Reply with the package you want and I’ll send the invoice.”
- “Send the deposit and I’ll send the intake form.”
- “If you already paid, send the brand name, deadline, references, and files.”
- “I can start with the quick fix first, then upgrade you into the full package.”
